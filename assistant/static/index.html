    版本说明

    v0.4.0：Windows 安装 EXE 内置 Python 与 Chromium；首次启动主动同意协议。新增独立批量余量监测，默认5秒更新，可调整策略；推荐顺序不修改原志愿。

    • 三入口导航、底部计划栏，以及按需展开的七步指引和侧边面板。
    • 按教务原有列完整显示课程信息，支持搜索、分页和页码跳转。
    • 同步已有课表，分别检查计划之间及与已有课程的时间冲突。
    • 保留黑白主题、红色校徽、演练结果与耗时反馈，以及自动下载或内置浏览器。

    学校模式支持课程读取、预选与冲突检查；真实选课提交尚未启用。演练结果仅用于功能体验。

    执行设置

    关闭后严格按个人优先级执行；页码只用于同等条件的排序。

    可设置 0–10 次。重试次数不包含首次提交；默认 3 次重试，共最多 4 次提交。人数已满不会盲目重试。

    监测目标与排序设置

    班代码会自动匹配内部 lessonId。基础信息缓存后，每轮只发送一次人数查询。

    查询模块不提交选课。满员、冲突、时间未知、已成功及过期数据不进入可用推荐顺序；接口限流时会延长等待。连续5轮失败后暂停，原志愿顺序保持不变。
