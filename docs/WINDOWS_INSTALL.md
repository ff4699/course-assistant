# CUPK 选课助手 Windows 安装与使用说明

版本：0.4.0；适用 Windows 10/11 x64。免费个人开源工具，非学校官方软件。

1. 双击 CUPK-Course-Assistant-Setup-0.4.0-x64.exe，按中文向导安装；无需另装 Python 或谷歌浏览器。
2. 打开“CUPK 选课助手”桌面快捷方式，阅读协议。默认不勾选同意框；同意并继续才进入助手，拒绝会退出。
3. 界面使用随包 Chromium。正常登录教务系统，人工填写验证码；再导入课表、同步课程、选择计划和检查冲突。
   如需余量查询：顶部“余量监测”→输入最多5个教学班代码，或填入当前计划→保存→开始。默认5秒，采用一次批量人数查询；暂停/停止保留数据，推荐顺序不改原志愿。学校接口限流时延长等待。
   可展开“当前目录人数快照”，一次查询当前目录；按钮仅在正常学校页面已证明支持当前批量数量后启用。当前范围14个教学班已实测，不代表全校全集。
4. 目前本校真实课程提交尚未启用。模拟演练只用于体验流程、耗时和结果展示，不能当作实际选课成功。
5. 关闭助手界面会正常停止服务并保留个人数据；运行控制窗口也可重新打开界面或退出程序。退出时请等待保存完成。

## 安装与个人数据

默认程序位置：%LOCALAPPDATA%\Programs\CUPKCourseAssistant
默认个人数据：%LOCALAPPDATA%\CUPKCourseAssistant\data

个人数据包括课表、计划、设置、结果、协议同意记录，以及 ui-profile 与 browser-profile 浏览器配置目录。浏览器会话可能允许继续访问你的账号，不要把这个文件夹发给别人。程序不在数据库、配置、日志或导出中持久化密码，浏览器关闭密码保存和自动填充。

程序在 127.0.0.1 的本地端口运行，通常为8766；占用时尝试后续9个端口。不会向局域网开放服务。学校登录和课程读取需要网络，内置浏览器不等于学校数据离线可用。

开发源码版本的 .state 不会自动搬到安装版，也不会进入公开安装包。当前开发中的学校会话不受安装测试影响。不要自行复制个人 Profile 到发布包。

## 升级与卸载

升级前正常退出安装版助手，再运行新版安装程序。不要在助手运行时覆盖程序文件。升级保留个人数据；协议内容实质更新后会重新询问同意。

卸载：Windows“设置 → 应用 → 已安装的应用 → CUPK 选课助手 → 卸载”。默认只删除安装程序文件，保留个人数据。

如需彻底清理：先在学校页面退出账号，再关闭助手；按 Win+R，输入 %LOCALAPPDATA%\CUPKCourseAssistant，确认这是本工具的个人数据目录后，手动删除其中的 data 文件夹。它会删除计划、课表、结果、同意记录和登录会话，未导出的资料无法恢复。不要删除其他软件目录。

## 常见问题

- 安装包缺少浏览器或依赖：重新运行完整安装包；不要只复制 CUPKCourseAssistant.exe。
- 学校提示重新验证：在正常学校窗口人工登录；无需删除 Profile，也不要向他人提供密码或验证码。
- 本地同意记录无法写入：检查当前 Windows 用户对数据目录的写入权限。
- 异常断电后升级提示仍在运行：先重新启动安装版，再正常退出后升级。
- 当前发布未购买代码签名证书，Windows 可能显示“未知发布者”。核对发布来源与随包 SHA256；文件校验值不同则重新获取，不需要关闭安全软件。
