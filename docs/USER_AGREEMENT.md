# CUPK 选课助手用户使用协议与隐私说明

协议版本：1.0；发布日期：2026-10-13。


## 1. 项目性质与费用

CUPK 选课助手是面向中国石油大学（北京）克拉玛依校区的个人开发、本地运行的免费开源工具，并非学校官方软件。校名和校徽用于说明适用学校，其权利归相应权利人所有。

本项目官方发布版本不收取安装费、使用费、订阅费或选课服务费，不设置付费解锁，也不以保证选课成功为由收费。遇到第三方收费、索要密码或冒充作者的情况，请自行核实来源。

## 2. 密码与登录会话

**本程序不将用户密码保存到本地数据库、配置文件、应用日志或导出文件，也不上传给项目作者。** 登录时的密码只用于在当前正常学校登录页面完成验证，不作为应用持久化数据保存。

为了减少重复登录，内置浏览器会在本机保存 Cookie、网站存储和其他登录会话数据。这些数据不是程序保存的密码，但可能允许继续访问已登录账号，应像个人账号资料一样保护。请不要将个人浏览器配置目录、数据库或整个用户数据文件夹发送给他人。共享电脑使用后应退出学校账号，并按程序提供的说明清理本地会话。

学校网站、操作系统及用户自行安装的其他软件有各自的数据处理行为，本说明不代表它们的隐私政策。

## 3. 本地数据与网络访问

课程目录、个人课表、选课计划、设置和执行记录保存在当前电脑，用于缓存、冲突检查和结果展示。同意协议后，程序仅在本地记录协议版本与同意时间，不为此收集姓名、手机号或密码。

正常使用时，程序会连接学校认证、教务及其正常页面所需服务；登录和课程查询需要网络。本项目不设置向作者服务器上传密码、课表、计划或使用记录的功能。课程记录可能包含个人信息，请妥善保管本地数据及主动导出的文件。

## 4. 使用方式与结果确认

请仅使用自己的账号，遵守学校选课规定，正常完成登录及人工验证，不利用本工具绕过验证码、访问控制或学校限制。

课程名额、开放时间、网络状态和学校系统反馈可能影响结果，本工具不承诺抢课速度或选课成功。最终结果以学校教务系统的实际记录为准，使用者应核对课程、教学班、时间和选课结果。

**当前版本尚未启用本校真实课程提交。模拟演练、计时和模拟成功提示不代表已在学校选课。** 后续若开放真实提交，应在版本说明中明确说明，并由用户确认目标计划后执行；同意本协议本身不等于授权立即选课。

## 5. 开源许可与署名

源代码的使用、修改和再分发，依项目正式发布的开源许可证执行；第三方组件依各自许可证执行。本协议不替代或限制这些许可证授予的权利。发布包保留相关版权声明、许可证及素材来源。

项目署名：校区25级机械某不知名发烧友。

## 6. 同意、拒绝与查看

安装后首次启动，程序先展示本协议；“我已阅读并同意《用户使用协议与隐私说明》”默认不勾选。用户主动勾选并点击“同意并继续”后，才可进入助手和连接学校系统；点击“不同意并退出”则关闭程序。

用户可随时在“关于”中查看协议、版本说明与开源声明。涉及密码处理、数据用途或费用的实质变化，应重新展示协议并征求同意。

## 7. 卸载与数据清理

卸载默认保留本机课表、计划和登录会话，以便重新安装后恢复。卸载界面或随包说明应明确给出单独清理这些数据的方法；清理须由用户主动选择，不自动删除其个人资料。

如不再使用本程序，建议先退出学校账号，再根据说明删除本地个人数据。删除后，未导出的计划和记录可能无法恢复。
